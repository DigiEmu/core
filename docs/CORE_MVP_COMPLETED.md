# DigiEmu Core – MVP Completed

DigiEmu Core MVP has been completed and released.

## Release

- Tag: `v0.1.0-core-mvp`
- GitHub Release: DigiEmu Core MVP

## Completed capabilities

- deterministic snapshot engine
- bundle manifest generation
- bundle verification
- replay bundle command
- replay determinism verification
- snapshot hash integrity verification
- replay hash persistence
- bundle export/import
- bundle signature layer
- trusted identity layer
- identity export/import
- identity fingerprint

## Verified pipeline

DigiEmu Core now supports the following end-to-end flow:

- create snapshot
- generate bundle
- verify bundle
- replay bundle
- verify replay determinism
- sign bundle
- verify signature
- export/import identity
- identify signer by fingerprint
- export/import bundles

## Outcome

DigiEmu Core is now a deterministic, portable, verifiable and signable
knowledge artifact infrastructure.
